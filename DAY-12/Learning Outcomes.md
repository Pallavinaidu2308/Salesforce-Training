## 🎯 Learning Outcomes

By completing this module, I developed an understanding of how a Salesforce application moves from development to a controlled production environment.

### 🔹 Version Control with Git

Learned how Git helps maintain Salesforce source code, track changes, collaborate with developers, and maintain a reliable development history.

### 🔹 Git Workflow

Learned to work with **branches, commits, push, pull, and Pull Requests** to develop and review changes safely.

### 🔹 Salesforce Metadata

Understood the difference between **code, metadata, and business data**, and how Salesforce configuration is represented as source code for version control.

### 🔹 Salesforce CLI

Learned how to use the modern **Salesforce CLI (`sf`)** to authenticate Orgs, retrieve metadata, deploy changes, run tests, and manage development environments.

### 🔹 Environment Management

Understood the purpose of **Developer Orgs, Sandboxes, Scratch Orgs, QA, UAT, and Production environments** and how changes move between them.

### 🔹 Deployment Methods

Learned the purpose and differences of **Salesforce CLI, Changesets, and Metadata API** for moving Salesforce metadata between environments.

### 🔹 Deployment Dependencies

Learned to identify dependencies between **LWC, Apex, Objects, Fields, Flows, Permissions, and other metadata** before deployment.

### 🔹 Testing & Validation

Understood why applications should be **tested, validated, and verified** before moving to Production.

### 🔹 Conflict Resolution

Learned how to identify and safely resolve **Git merge conflicts** by understanding the actual business requirement instead of blindly choosing a version.

### 🔹 Professional Deployment Workflow

Understood the complete development lifecycle:

```text
Developer
   ↓
Feature Branch
   ↓
Commit & Push
   ↓
Pull Request
   ↓
Code Review
   ↓
Testing
   ↓
QA
   ↓
UAT
   ↓
Production
   ↓
Verification
```

### 🔹 Professional Documentation

Learned how to structure a **GitHub repository and deployment documentation** so another developer can understand, reproduce, test, and deploy the project.

### ⭐ Overall Outcome

This module helped me move from **"building Salesforce features"** to understanding how to **build, version, review, test, document, and safely deliver a Salesforce application** as part of a professional development workflow.
