# 🔄 HTTP Methods

HTTP methods define the operation that Salesforce wants to perform on an external API.

| Method | Purpose |
|--------|---------|
| GET | Retrieve data |
| POST | Create/send data |
| PUT | Replace a resource |
| PATCH | Partially update a resource |
| DELETE | Delete a resource |
